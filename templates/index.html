Normal Exam
Admin-controlled availability
You decide when it's live — flexible enough to reuse for makeup sessions and practice rounds.
  • Flexible, admin-controlled Live status
  • Start any time while the exam is Live
  • Attempts governed by a configured limit
  • Can be made reusable without re-scheduling
VS
Scheduled Exam
Fixed, automated timeline
Set it once — the platform opens, times and closes it for you, to the second.
  • Fixed scheduled window, start to finish
  • Preparation / buffer period before it opens
  • Secure preparation kiosk with countdown
  • Automatic start, timing and submission
