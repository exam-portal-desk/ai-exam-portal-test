# PGADMIN DATABASE PASSWORD RESET QUERY
----------------------------------------------------------------

PostgreSQL Local Superuser Password Reset

1. Open pgAdmin 4 and connect to the local PostgreSQL server using the existing `postgres` superuser connection.

2. Open Query Tool for the connected PostgreSQL server.

3. Execute the following command:

ALTER USER postgres WITH PASSWORD 'YOUR_NEW_PASSWORD';

4. Replace `YOUR_NEW_PASSWORD` with the new local PostgreSQL password you want to use.

5. Verify that the query completes successfully.

6. Use the following local PostgreSQL connection string format:

postgresql://postgres:YOUR_NEW_PASSWORD@localhost:5432/YOUR_DATABASE_NAME

7. Store the connection string in the local `.env` configuration as:

DATABASE_URL=postgresql://postgres:YOUR_NEW_PASSWORD@localhost:5432/YOUR_DATABASE_NAME

Note:
- Use a strong password.
- Avoid special characters such as `@`, `:`, `/`, and `#` in the password unless they are properly URL-encoded.
- This password applies only to the local PostgreSQL instance.
